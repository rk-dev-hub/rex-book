# テスト方針

## 1. 対象とツール

| 対象 | ツール | 中身 |
| --- | --- | --- |
| 空き枠算出・予約ルール・チケットの予約可能回数 | pytest（RexCarte） | `04-availability-spec.md` §7 の表を網羅。`now` を固定して決定的にする |
| 同時予約 | pytest（RexCarte） | 別セッション 2 本で同時に INSERT し、排他制約で 1 件だけ成功することを確認 |
| 認証・認可・情報漏えい | pytest（RexCarte） | トークン種別の分離、他人の予約、エラー本文にスタッフ名・理由が無いこと |
| 日時表示・URL クエリの組み立て | Vitest（RexBook） | 純粋関数 |
| 主要フロー | Playwright（RexBook） | RexCarte・Mailpit を起動した状態で、メールのコード取得から予約・キャンセルまで |

## 2. デモデータ

- RexCarte の `scripts/seed_demo.py` が、店舗の Web 予約 ON・予約受付設定・公開チケットプラン・スタッフ、顧客として登録済みの顧客（チケットあり・なし・電話番号未登録・複数店舗登録など）を投入する。
- ワンタイムコードはローカルでは Mailpit で確認する（固定コードの裏口は作らない）。
